# User Manual (Admin)

## Access

Navigate to `admin.jagadeeswar.com` (or `http://admin.localhost:3000` locally).

## Login

Use the configured credentials to log in.

## Dashboard

- **Blog Management**:
  - View all posts.
  - Create New Post: Markdown editor supported.
  - Edit/Delete posts.

- **AI Knowledge Base**:
  - Upload text/PDF files.
  - The AI agent will ingest these files to answer questions about you.
  - "Files" tab allows you to see what the agent knows.

## AI Chat

On the main website (`jagadeeswar.com`), visitors can chat with the AI. The AI uses the knowledge base you uploaded to answer questions.
